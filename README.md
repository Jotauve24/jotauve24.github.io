- [TrazoJV](https://jotauve24.github.io/trazo/) — herramienta para añadir una firma visual a documentos PDF directamente en el navegador.

## Privacidad de TrazoJV

TrazoJV funciona sin registro. Los documentos se procesan localmente en el navegador y no se envían a un servidor. La firma insertada es visual y no sustituye una firma digital criptográfica certificada.
